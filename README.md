# 📞 Call Logger

**A lightweight Python tool to log and save your calls, right from Termux.**

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Android%20%7C%20Termux-3DDC84?logo=android&logoColor=white)

</div>

---

## 🚀 Quick Start

```bash
python Logger.py
```

## 📂 Output

Call logs are saved to:

```
Documents/call_logs
```
